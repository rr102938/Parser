# Context-Free Grammar Parser (CS50 AI)

## What it does
* This is a Python program that uses Natural Language Processing (NLTK) and Context-Free Grammar (CFG) rules to parse sentences.
* It breaks down sentences into syntax trees and extracts all the noun phrase chunks automatically.

## Technologies Used
* Python
* NLTK (Natural Language Toolkit)
* Git / GitHub

## How to Run It
* Make sure you have NLTK installed on your computer by running this in your terminal:
  * ```bash
  * pip install nltk
  * Run the Python script: python parser.py
  * Type a sentence when prompted, or pass a text file as an argument.
